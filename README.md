# SafeBox Frontend

Веб-интерфейс SafeBox v2 — локального зашифрованного сейфа. Тёмная тема,
минимум лишних нажатий: инлайн-переименование по **F2**, ссылка добавляется
**Ctrl+V** в любом месте окна, файлы и папки — **drag&drop**.

## Скачивание из браузера прямо в сейф

Веб-страница не может «раскрыть» сейф как настоящую папку ОС, поэтому цель
«скачал в браузере → сразу в сейф» решается тремя способами:

- **Наблюдение за папкой** (Chromium: Chrome/Edge). «Импорт → 👁 Следить за
  папкой…» → выбрать «Загрузки» один раз. Всё новое, что браузер сохраняет
  туда, попадает в сейф автоматически через ~4–8 с (файл ждёт, пока размер
  стабилизируется; `.crdownload`/`.part` игнорируются; существующие файлы не
  трогаются). Состояние — чип 👁 в статусбаре (✕ — отключить). Папка и
  отпечатки переживают перезагрузку вкладки; после блокировки сейфа
  наблюдение останавливается вместе с сессией.
- **Ctrl+V картинки**: «Копировать изображение» на любой странице → Ctrl+V
  в окно SafeBox → файл в сейфе с именем «Вставлено дата время.png».
- **Перетаскивание** из панели загрузок браузера в окно (работало и раньше).

## Защита от дублей

Сервер по контракту v2 не проверяет записи на дубликаты (409 есть только у
создания файла сейфа), поэтому проверка на клиенте до отправки:

- **файл-дубликат** = то же имя + тот же размер байтов среди записей целевой
  папки (кэш листинга, при промахе — запрос). Дубли отсеиваются, тост честно
  сообщает: «Импортировано: N, дубликатов пропущено: M» или «Уже в сейфе:
  N дубликатов». Действует для файлов верхнего уровня; вложенные пути
  («Папка/файл») попадают в подпапки и сравниваются только внутри партии.
- **ссылка-дубликат** = та же страница (точное совпадение URL); разные
  страницы одного сайта — это разные ссылки.
- Вставленные по Ctrl+V картинки получают имена с датой-временем — каждая
  вставка считается новой (как скриншоты). Нужна копия существующего файла —
  переименуйте его до повторного импорта.

## Стек

- Vite 5, TypeScript 5.5 (strict, `noUncheckedIndexedAccess`)
- React 18 + Tailwind CSS 3.4 (тёмная тема)
- TanStack Query 5 (кэш, инвалидация, статус загрузки)
- vitest + Testing Library; Playwright для e2e

## Запуск (dev)

Бэкенд — собранный `safeboxd` из репозитория safebox-backend:

```powershell
<path-to-safebox-backend>/build/msvc-debug/src/daemon/safeboxd.exe `
  --allow-origin http://localhost:5173 --allow-origin http://127.0.0.1:5173
```

```bash
npm install
npm run dev        # http://localhost:5173, /api -> 127.0.0.1:8900 (changeOrigin)
```

## Сборка и встраивание

`npm run build` собирает `dist/`. Чтобы вшить фронт в `safeboxd.exe`,
сборка бэкенда запускается с `-DSAFEBOX_WEB_DIST=<путь к dist>` (см. README
бэкенда).

## Тесты

```bash
npm test           # vitest: формат, ссылки/.url, дерево имён, NameEditor
npm run typecheck  # tsc --noEmit
npm run e2e        # Playwright; глубокий сценарий — SAFEBOX_E2E=1 + SAFEBOX_E2E_PATH
```

## Контракт API

`src/api/types.ts` рукописный и синхронизирован с `docs/api.md` репозитория
бэкенда (источник правды). Токен сессии — `sessionStorage`; медиа (`<img>`,
`<video>`, скачивание) ходят через HttpOnly-cookie `sbx_media`, токен в URL
не попадает никогда. Любой 401 = мёртвая сессия → экран входа.

## Горячие клавиши

| Клавиши            | Действие                                    |
|--------------------|---------------------------------------------|
| `F2`               | инлайн-переименование (выбранной/наведённой карточки) |
| `Delete`           | удалить выделение (с подтверждением)        |
| `Ctrl+A`           | выделить всё в текущем виде                 |
| `Ctrl+клик` / `Shift+клик` / чекбокс | мультивыделение / диапазон |
| `←` `→` `Home` `End` | перемещение по карточкам                  |
| `Enter`            | открыть выбранное                           |
| `Ctrl+V`           | ссылка из буфера; картинка → импорт в сейф |
| `Esc`              | закрыть просмотр → снять выделение → сбросить поиск |

Добавление ссылки без отдельного окна: вставьте URL в поле «Ссылка ↵» сверху
или просто `Ctrl+V` в любом месте — фронт синтезирует ярлык Windows `.url`
и импортирует его контрактным `POST /api/v1/import`, сервер распознаёт его
как ссылку (`docs/api.md` §7).

## Присутствие и автоблокировка (UF-13)

Каждые 20 с уходит `POST /safe/heartbeat {active}`; активность — мышь,
клавиатура, навигация, а также длинные действия (импорт, воспроизведение
видео отмечают её принудительно). При `idleRemainingSec <= 60` показывается
предупреждение с кнопкой «Остаться»; после блокировки любой запрос даёт 401
и приложение само показывает экран входа.
